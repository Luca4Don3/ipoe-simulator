# Support

GitHub Issues are for reproducible defects and documentation problems in the latest formal Release or current `main`. Include the version, operating system, architecture, command category, expected result, actual result, and a minimal reproduction using synthetic data.

This project does not provide emergency network recovery, production operations, IPTV service credentials, operator configuration, or assistance using networks and devices without authorization. Real PCAP/PCAPNG files, configuration, logs, recovery journals, device identifiers, interface details, and infrastructure addresses must not be posted publicly.

Use `SECURITY.md` instead of a public Issue when a report concerns a vulnerability, credential, privacy exposure, or unsafe restoration behavior.
